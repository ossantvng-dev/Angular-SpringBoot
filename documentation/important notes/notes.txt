Angular CLI

Create a new app
	
	ng new angular-app
	
Create new component

	ng g component counter
	
	ng g c components/invoiceList
	
Create a new Service
	
	ng g service services/item
	
	
Install ngrx
	
	ng add @ngrx/store@latest
	
Install dev tools
	
	Redux DevTools in your browser.
	
	ng add @ngrx/store-devtools@latest
	
Install effects
	
	ng add @ngrx/effects@latest
	
	
Run local build
		
	npm run build
	
Run production build
	
	npx ng build --configuration production

To run the app and point to local backend either spring boot or micronaut use
	
	ng serve
	
To run the app and point to remote backend in AWS

	 npx ng serve -c production
